# Campus Resource and Event Management

Role-based campus platform for events, resources, clubs, and messaging with dedicated admin, organizer, and participant experiences.

## Highlights

- Role-based access: admin, organizer, participant
- Events: create, approve, publish, register, close, notify
- Resources: catalog, booking requests, approvals
- Clubs: memberships and leadership views
- Notifications and chat threads with moderation tools
- Admin console: users, approvals, system settings, audit logs
- Google OAuth login defaults new users to the participant role
